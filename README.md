# scribble

小红书端的图文，一篇一个文件，正文与发布稿逐字一致，配图原样存档。

主题集中在 AI 订阅怎么选档、额度怎么估、多设备怎么算、一百块预算怎么搭——都是「自己用得上」的那部分，不写新闻和感想。

## 目录

| 篇名 | 一句话摘要 | 链接 |
|---|---|---|
| 我的AI工具清单，最后只留了5个 | 按使用频率排出五类必留工具，给出一条「断供就得有替换」的取舍标准 | [01](notes/2026-11-06_我的AI工具清单最后只留了5个.md) |
| AI订阅到底该买哪一档？按预算分三档说清 | 档位按「每天用几次」分，不按钱分；每档给判断信号和配法 | [02](notes/2026-11-06_AI订阅到底该买哪一档.md) |
| 预算100块，AI工具怎么搭 | 三套「主力 + 补位 + 免费顶」的组合，按用例分不按价位分 | [03](notes/2026-11-06_预算100块AI工具怎么搭.md) |

## 结构

```
notes/    每篇一个 md，头部 YAML 记 title / date / platform / tags / images
images/   每篇一个目录，三张 1080×1440（1封面 + 2详图）
```

## 说明

- 正文即发布稿原文，一个字没动；配图是本机出图的原件，没有二次压缩。
- 每篇 md 的 YAML 里 `images` 字段列了配图的相对路径，点开就能对上。
- 图文只把选择逻辑讲清楚，具体在哪买、多少价钱不在正文里写——价格随时会变，看实时页最准。
